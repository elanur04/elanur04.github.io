# Elanur Beycan · Portfolio

[Canlı site](https://elanur04.github.io/) · [GitHub](https://github.com/elanur04) · [LinkedIn](https://www.linkedin.com/in/elanurbeycan)

CV ve proje depoları temel alınarak hazırlanmış Türkçe / İngilizce kişisel portfolyo. Bağımlılık, derleme adımı veya API anahtarı gerektirmez; GitHub Pages üzerinde statik olarak çalışır.

## Özellikler

- GeoSim’den esinlenen özgün Canvas şehir illüstrasyonu; duraklatma, azaltılmış hareket tercihi ve ekran dışında animasyonu durdurma.
- Beş seçili proje, alan filtreleri ve katkı / sonuç / sınırları açıklayan proje pencereleri.
- Türkçe / İngilizce dil seçimi; seçim tarayıcıda saklanır. İndirilebilir CV Türkçedir.
- Eğitim, staj, sertifikalar, topluluk çalışmaları ve teknik beceriler.
- E-posta, adres kopyalama, LinkedIn, GitHub ve CV bağlantıları.
- Mobil menü, klavye erişimi, native dialog odak yönetimi ve JavaScript olmadan okunabilir ana içerik.
- Sosyal paylaşım görseli, canonical adresi, sitemap ve robots.txt.

## Yerel çalıştırma

Bu klasörde `python -m http.server 8080` komutunu çalıştırın ve `http://localhost:8080` adresini açın. HTML dosyası doğrudan da açılabilir; pano erişimi için localhost veya HTTPS gerekir.

## İçeriği güncelleme

- Türkçe ana içerik: `index.html`.
- İngilizce çeviriler ve iki dilde proje ayrıntıları: `script.js` içindeki `en` ve `details` nesneleri.
- Tasarım ve responsive kurallar: `style.css`.
- CV: `Elanur_Beycan_CV.pdf` (25 Kasım 2026 düzenlemesinde sağlanan CV44 dosyasının aynısı).
- Paylaşım görseli: `assets/social-preview.png`.

Şehir, ağ, bulut ve yerleştirme görselleri projeleri anlatmak için hazırlanmış illüstrasyonlardır; uygulama ekran görüntüsü veya canlı proje verisi değildir. Makine öğrenmesi metrikleri proje deposundaki notebook sonuçlarına dayanır. Google Fonts erişilemezse sistem fontlarına geçilir.
